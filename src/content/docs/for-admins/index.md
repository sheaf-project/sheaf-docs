This section documents the complete set of capabilities an instance admin has
through the Sheaf UI: user management, approvals, invites, announcements,
background jobs, the audit log, and security settings.

It is written for two audiences at once:

- **Admins**, who need to know how to run an instance.
- **Users**, who deserve to know exactly what the admin of their instance can
  and cannot see or do. Each page includes a "what this means for you as a
  user" note.

An admin with direct database access can do more than the UI exposes - that is
true of any hosted service, and these docs say so plainly rather than
pretending otherwise. What you see here is the full *supported* admin surface.

Docs are being written.
